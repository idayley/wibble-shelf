# Trim Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** `items/trim/` — a shelf extension that decides which old tool results to drop and pushes them to Wibble, judged by a local OpenJev service, and shows what it saved as a top-slot pill.

**Architecture:** `main.js` listens to `wibble.trim.onSeen` / `onResult`, keeps per-thread item state, asks the local judge (`wibble.net.fetch` to `127.0.0.1:8791/v1/systemone`) in the background, releases drops every 20 calls, and keeps a running saving in storage. `openjev-serve.py` is a tiny Jev-compatible HTTP server around the 4-bit Qwen3.5-4B OpenJev model (semif MLX) that the operator starts once.

**Spec:** `docs/specs/2026-09-26-trim-design.md`; Wibble side: `wibble/docs/superpowers/specs/2026-09-26-context-trim-capability-design.md` (worktree `.claude/worktrees/engine-route`).

```ts

wibble.net.fetch(url, { method, headers, body }): Promise<{ status: number; headers: object; body: string }>
```

### Task 1: The rule and the saving, as pure functions

**Files:** Create `items/trim/logic.js` (ES module, no globals, imported by `main.js` — if the extension loader only loads `main`, inline it into `main.js` at the end instead and export the pure functions for tests), `items/trim/logic.test.mjs` (run with `node --test`).

Exports:
- `track(state, seen)` — `state.threads[key]` where `key = sessionId + ":" + thread`: `{ calls, lastRelease, items: Map(id → {tool, target, chars, age, head, verdict: null|{notNeeded:number}, asked:boolean}) , dropped:Set, droppedTargets:Map(target→chars) }`. Updates `calls` and each item's latest `age`/`chars`; keeps `head` once seen. Returns `{ toJudge: items with age > AGE, no verdict, not asked, not dropped }`.
- `release(thread, judgeUp)` — when `thread.calls - thread.lastRelease >= BATCH`: ids with `age > AGE`, not already dropped, and (`verdict?.notNeeded >= NOT_NEEDED_P` **or** (`!verdict` and the fallback applies)). Fallback applies to an item with no verdict always (judge down *or* not reached yet — spec §3). An item whose verdict says needed (`notNeeded < 0.7`) is kept. Sets `lastRelease = calls`, adds to `dropped`, records `droppedTargets`. Returns the ids (possibly empty). First release happens as soon as `calls >= BATCH`.
- `rereads(thread, seen)` — items with `age === 0` whose `target` is in `droppedTargets` and that are new ids: returns their total `chars` (charged once per id).
- `cost(usage)` in input-token units: `input*1 + cacheRead*0.1 + cacheWrite5m*1.25 + cacheWrite1h*2 + output*5`.
- `saving(result, rereadChars)` in the same units:
  - `promptTokens = input + cacheRead + cacheWrite5m + cacheWrite1h`; `r = promptTokens / max(1, totalChars)` (tokens per char, self-calibrating per request).
  - `writeW = cacheWrite1h > cacheWrite5m ? 2 : 1.25`; `unitPrice = cacheRead > 0 ? 0.1 : writeW`.
  - `gross = removedChars * r * unitPrice`.
  - `cut = firstCutChars == null ? 0 : max(0, totalChars - firstCutChars) * r * (writeW - 0.1)`.
  - `reread = rereadChars * r * writeW`.
  - returns `{ saved: gross - cut - reread, actual: cost(usage), removedTokens: removedChars * r }`.
- `PRICE_PER_M` = `{ opus: 5, sonnet: 3, haiku: 1 }` matched by substring of `model`; `dollars(units, model)` → `units * price / 1e6` or `null` when unknown.
- `percent(totals)` = `saved / (actual + saved)`.

Tests (hand-worked numbers in the test file's comments):
- [ ] no release before 20 calls; release at 20 drops only age > 5; a "needed" verdict is kept; unjudged items are dropped (fallback); dropped ids never returned twice.
- [ ] `saving` on a warm request: `usage={input:10,cacheRead:90000,cacheWrite5m:1000,cacheWrite1h:0,output:500}, totalChars=364040, removedChars=40000, firstCutChars=null` → `r = 91010/364040 = 0.25`, `gross = 40000*0.25*0.1 = 1000`.
- [ ] same with `firstCutChars = 300000` → `cut = 64040*0.25*1.15 = 18411.5`, so `saved = 1000 - 18411.5` (a cut request costs; later requests pay it back) — and a three-request sequence (cut, then two warm) sums to the value computed by hand in the comment.
- [ ] `dollars` for `claude-opus-5` and unknown model.

### Task 2: The judge client and `main.js`

**Files:** Create `items/trim/wibble.json`, `items/trim/main.js`.

`wibble.json`:
```json
{
  "id": "trim", "name": "Trim",
  "description": "Quietly removes old tool output your agents no longer need, so every request costs less. Shows what it saved.",
  "version": "1.0.0", "author": "idayley", "main": "main.js", "api": 1, "slot": "top",
  "capabilities": ["panel.render", "storage", "context.trim", "net.fetch"],
  "hosts": ["127.0.0.1:8791"]
}
```

`main.js`:
- Judge: `ask(item, seen)` posts to `http://127.0.0.1:8791/v1/systemone`:
  ```json
  { "model": "openjev", "state": "<the state text>",
    "questions": { "stale": { "type": "noul", "instructions": "Will the agent still need this tool output to finish the operator's current request? Answer how likely it is NOT needed." } } }
  ```
  state text = `Operator's latest request:\n<lastUser>\n\nAgent's recent messages:\n<recentAssistant>\n\nTool output under question:\n<tool> <target>\n<head or "(content not shown)">` (each part capped: 1500/1500/1200 chars). Response `answers.stale.noul` (0..1) → `verdict = { notNeeded: p }`. One request in flight at a time, queue newest-thread-first, cap queue 200 (drop oldest). A failure or non-200 marks the judge down for 60 s (`judgeUp = false`), and nothing is retried in that window. Health probe: `GET /health` on start and every 60 s while down.
- `onSeen`: `track` → enqueue `toJudge`; `rereads` → stash for the next result of that session+thread; `release` → `wibble.trim.drop(sessionId, ids)` when non-empty.
- `onResult`: `saving(...)`; add to `totals` for today (`YYYY-MM-DD` key) and keep 14 days; persist to storage `totals` at most every 5 s.
- Panel (`wibble.panel.set("Trim", node)`), top-safe, redrawn at most once a second:
  - Nothing recorded yet: `{kind:"chip", label:"Trim", tone:"quiet"}`.
  - Else a `row`: `chip` `−24%` (percent this week, rounded) and `text` `$41 saved this week` (or `1.2M tokens saved this week` when dollars unknown), and when the judge is down a `text` `age rule` .
  Check the exact node shapes/tones against `make-an-extension.md` and `items/claude-usage/main.js`.
